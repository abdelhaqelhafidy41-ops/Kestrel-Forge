# Brand Identity & Design System — Kestrel Forge

## 1. Brand Name Evaluation (5 Candidates)

| Candidate | Domain Style | Evaluation (Memorability, Visual Potential, Dual Gaming + Pro Software Fit) |
| :--- | :--- | :--- |
| **1. Kestrel Forge** *(Selected)* | `kestrelforge.*` | Crisp two-word compound: *Kestrel* evokes speed, precision, and agility; *Forge* evokes engineering, builds, and crafting software & games. High visual logo potential (geometric wing + prism anvil). Works seamlessly for both indie games and native Windows/Android utilities. |
| **2. Veltrix Studio** | `veltrix.*` | Modern, sleek tech sound. Strong for web apps and gaming, slightly abstract for developer/system utilities. |
| **3. Arkline Labs** | `arkline.*` | Clean architectural feel. Great for desktop tools and SaaS, slightly less energetic for action/strategy games. |
| **4. Cobalt Grid** | `cobaltgrid.*` | Strong geometric and engineering identity, though closer to a UI framework or infrastructure brand than a consumer game store. |
| **5. Novara Soft** | `novarasoft.*` | Friendly and international, but feels closer to a legacy software house than a modern futuristic platform. |

> **Note**: Domain availability has not been queried against a live registrar and must be verified before registration.

---

## 2. Logo & Iconography Concept

- **Mark**: An angular geometric kestrel wing intersecting an isometric diamond prism—representing precision compilation and interactive worlds.
- **Favicon**: `/public/favicon.svg` — scalable monochrome-ready mark with electric indigo (`#6366F1`) and cyan (`#22D3EE`) gradient core.

---

## 3. Color Palette & Typography

- **Dark Surface Canvas**: `#09090B` (Obsidian Black)
- **Elevated Surface**: `#111114` (Charcoal Slate) with `1px` hairline borders (`rgba(255, 255, 255, 0.08)`)
- **Primary Accent**: Electric Indigo `#6366F1` -> `#4F46E5`
- **Secondary Highlight**: Cyan `#22D3EE` (used sparingly for active technical indicators)
- **Light Mode Alternative**: `#FAFAFA` canvas with `#FFFFFF` surfaces and `#18181B` ink
- **Display Font**: `Plus Jakarta Sans` (EN) / `IBM Plex Sans Arabic` (AR)
- **Body Font**: `DM Sans` (EN) / `IBM Plex Sans Arabic` (AR)
- **Monospace Telemetry**: `JetBrains Mono` with `tabular-nums`
